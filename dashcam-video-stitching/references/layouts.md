# 排版模板与坐标计算

用 `xstack` 合成。核心是先在纸上把每个视角的 `x_y` 算对，再一次性写给 ffmpeg。

## xstack 基础

```
[0:v][1:v][2:v][3:v]xstack=inputs=4:layout=<x0>_<y0>|<x1>_<y1>|<x2>_<y2>|<x3>_<y3>:fill=black[o]
```

- 坐标是**左上角**，不是中心。
- 所有输入必须同像素格式（先 `format=yuv420p`）且尺寸在看板范围内。
- `fill=black` 决定画布底色；画布尺寸 = `max(x+w)` × `max(y+h)`，不会自动放大。
- 输入顺序即 `[0:v][1:v]...` 的映射顺序，跟坐标写法无关，容易错位——建议按固定顺序：主、左、后、右。

## 模板 A：主视角在上，三视角在下（默认）

适用于主视角宽度正好是侧视角宽度的整数倍（3840 = 3 × 1280）。

```
W = 3840, H = 1696        # 主视角
w = 1280, h = 1000        # 每路侧视角
tile_w = W / n = 1280
tile_h = tile_w * h / w = 1000
canvas = 3840 × (1696 + 1000) = 3840 × 2696
```

```
layout=0_0|0_1696|1280_1696|2560_1696
```

不能整除的例子（W=2560, n=3, w=800）：`tile_w = floor(2560/3) = 853` → 取偶 852，下排总宽 2556，右侧留 4px 黑边。可接受，不要拉伸。

## 模板 B：2×2 等分

四路同尺寸时最省事。若主视角更大，可先按 2×2 排再单独缩放。

```
canvas = 2W × 2H
layout=0_0|W_0|0_H|W_H
```

主视角占左上、其余三路占其余格子的"主视角放大版"：

```
[0:v]scale=2W:2H[main]            # 主视角占左半 + 上半
...
```
这类非等分网格建议直接算好坐标写死，不要试图用公式通用化——每个记录仪的宽高比都不同。

## 模板 C：下排统一高度（为了压低画布高度）

当模板 A 的画布太高（高度 > 2304 会触发解码兼容问题），可以把下排压扁到指定高度：

```
TILE_H = 600
每个侧视角：scale=-2:TILE_H  → 按宽高比自动算宽，宽度会小于 W/3
下排三路居中排布：x = (W - 3*tile_w)/2 + i*tile_w
```

代价是左右留黑边。**注意这是等比缩放，不算破坏几何**，但确实损失了侧视角的像素，要在交付说明里讲清楚。

## 计算辅助

```bash
# 输入各视角尺寸，算模板 A 的画布
scripts/probe.sh <源目录>     # 会直接打印推荐画布与每块 tile 的尺寸
```

## 拼接顺序陷阱

记录仪的文件名后缀（MAIN/LEFT/BACK/RIGHT）与实际画面方位不一定一致，尤其"后"摄像头有的会做镜像。**合成后务必抽一帧目视确认左右关系**，不要只看文件名。
